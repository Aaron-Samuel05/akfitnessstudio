# AK Fitness Studio

A brutalist, immersive 3D gym portfolio built with Next.js, React, TypeScript and React Three Fiber.

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000

The 3D hero is procedural, so there are no external 3D model files to download.

## Customize
- Studio city/address: `src/app/page.tsx`
- Email/social: `src/app/page.tsx`
- 3D scene: `src/components/3d/GymScene.tsx`
- Visual system: `src/app/globals.css`
